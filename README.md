# Mapping ABM research in the social sciences

This repository contains code and analyses for an ongoing project building on and adapting materials from the following preprint:

Thoma, A., Bolenz, F., Tiede, K., Yang, Y., Palminteri, S., Hertwig, R., & Wulff, D. (2025). *Mapping the landscape of behavioral reinforcement learning research*. PsyArXiv. https://osf.io/preprints/psyarxiv/6c2va_v1

## Acknowledgements and Source Material

A substantial portion of this project involves **editing, adapting, and (in places) directly copying code and analysis structure** from the original materials released by the authors associated with the preprint above (hosted on OSF/PsyArXiv).

All credit for the original code, analysis approach, and research ideas belongs to the original authors.  
This repository is intended as a derivative, project-specific workspace for experimentation, extension, and reproducible analysis in a new context.

If you use or build on this repository, please **also cite the original preprint** and consult the OSF page for the authoritative and most up-to-date materials:
https://osf.io/preprints/psyarxiv/6c2va_v1

## What this repository is

- A working, evolving project that adapts and extends existing research code and workflows.
- A space for development
- A reproducible record of modifications and additions relative to the original materials.

## What this repository is not

- An official release by the original authors.
- A replacement for the original OSF materials.
